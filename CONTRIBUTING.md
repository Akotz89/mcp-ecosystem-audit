# Contributing to MCP Ecosystem Audit

## How to Add a Server

1. Fork this repository
2. Add your server to `docs/server-directory.md`
3. Include: name, maintainer, transport support, star count
4. Submit a pull request

## Quality Criteria

Servers are evaluated on:
- **Stability**: Does it stay running without crashes?
- **Transport**: Does it support Streamable HTTP (recommended)?
- **Documentation**: Is there a clear README?
- **Maintenance**: Active commits in the last 6 months?

## Code of Conduct

Be respectful. Focus on technical merit.
